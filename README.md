# Motorola Sales Analysis Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard developed to analyse Motorola mobile sales performance, customer ratings, transactions and product trends.

## Tools Used
- Microsoft Power BI
- Data Visualisation
- Interactive Filters and Slicers

## Key Performance Indicators (KPIs)
- Total Sales: 769M
- Total Quantity: 19K
- Total Transactions: 4K
- Average Sales: 40K

## Analysis Performed
- Total Sales by City
- Monthly Quantity Trends
- Sales by Mobile Model
- Transactions by Payment Method
- Customer Ratings Analysis
- Sales Performance by Day
- Brand-wise Sales and Quantity Comparison

## Interactive Features
- Mobile Model filter
- Payment Method filter
- Brand filter
- Day Name filter
- Month selection
